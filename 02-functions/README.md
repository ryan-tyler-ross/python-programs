# Functions and small projects

Use functions and dictionaries, then practice importing your own modules.

- [caesar_cipher.py](caesar_cipher.py) — Return a letter-shifted message; encode or decode in the terminal.
- [calculator.py](calculator.py) — Store functions in a dictionary and reuse a calculation's result.
- [blind_auction.py](blind_auction.py) — Collect bids and return the highest bidder; ties favor the first bid.
- [number_guessing.py](number_guessing.py) — Guess 1–100 with 10 easy or 5 hard attempts; formerly mislabeled coffee_machine_v1.py.
- [blackjack.py](blackjack.py) — Compare hands with flexible aces; the dealer draws to 17. No betting or special blackjack payouts.
- [coffee_machine.py](coffee_machine.py) — Track ingredients and coin payments using dictionaries and functions.

- [Hangman](hangman/README.md) — Practice importing lists from neighboring files.
- [Higher or lower](higher-lower/README.md) — Compare follower counts from a fixed sample dataset.

Start from the course root: `python 02-functions/caesar_cipher.py`.
