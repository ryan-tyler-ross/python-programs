# Desktop programs

Small Tkinter applications. Each needs a graphical desktop with Tk support.

| Program | Purpose | Extra packages |
| --- | --- | --- |
| [miles_to_km.py](miles_to_km.py) | Convert miles to kilometers. | None |
| [Pomodoro timer](pomodoro-timer/) | Focus/break sessions, pause/resume, and Linux desktop alerts. | Pillow |
| [Password manager](password-manager/) | Local encrypted-file storage, search, and clipboard callbacks. | cryptography, pyperclip |

Entry example: `python3 desktop/miles_to_km.py`.
The [widget reference](../templates/tkinter/) lives with the templates.
