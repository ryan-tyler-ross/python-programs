# True or false quiz

Practice building objects from saved data and keeping score.

From the course root: `python 03-classes/quiz/main.py`.

- `main.py` — Build Question objects and ask each one exactly once.
- `question_model.py` — Store one question and its correct answer.
- `quiz_brain.py` — Manage question order, input validation, and score.
- `data.py` — The saved Open Trivia DB questions and answers used by this exercise.
