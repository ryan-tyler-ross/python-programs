# Coffee maker with classes

Read the procedural machine in 02-functions first, then compare how these objects share the work.

From the course root: `python 03-classes/coffee-maker/main.py`.

Type report for inventory and profit, or off to quit.

- `main.py` — Take orders and connect the menu, payment, and machine objects.
- `menu.py` — Define drinks, ingredient amounts, prices, and menu lookup.
- `coffee_maker.py` — Check and deduct ingredients; print the stock report.
- `money_machine.py` — Collect coins, return change, and track profit.
