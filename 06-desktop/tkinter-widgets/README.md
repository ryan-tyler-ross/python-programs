# Tkinter widgets

Start with the converter, then try the larger widget reference.

From the course root: `python 06-desktop/tkinter-widgets/miles_to_km.py`.

Run python widget_examples.py to explore the other widgets.

- `widget_examples.py` — Show common widgets and print their values when used.
- `miles_to_km.py` — Convert miles to kilometers with an entry, label, and button.
