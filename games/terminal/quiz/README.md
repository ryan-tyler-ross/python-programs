# True or false quiz

Entry: `python3 games/terminal/quiz/main.py`. Standard library only.
Saved questions are asked once each, with validated answers and a final score.

- [main.py](main.py): construct the question bank and run the quiz.
- [question_model.py](question_model.py): question text and answer.
- [quiz_brain.py](quiz_brain.py): question order, answer checks, and score.
- [data.py](data.py): saved Open Trivia DB questions.
