# Terminal games

| File or folder | Program |
| --- | --- |
| [blackjack.py](blackjack.py) | Simplified card game with flexible aces and a dealer that draws to 17. |
| [number_guessing.py](number_guessing.py) | Guess 1–100 with 10 easy or 5 hard attempts. |
| [rock_paper_scissors.py](rock_paper_scissors.py) | One round against a random computer move. |
| [treasure_island.py](treasure_island.py) | A branching text adventure. |
| [Hangman](hangman/) | Word guessing with a fixed word list and terminal artwork. |
| [Higher or lower](higher-lower/) | Compare counts from a saved sample dataset. |
| [True or false quiz](quiz/) | Questions, answer validation, and scoring through small classes. |

Standard library only. Entry example: `python3 games/terminal/blackjack.py`.
