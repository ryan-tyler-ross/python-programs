# Games

Simple games grouped by interface. Multi-file programs keep their helper modules
and sample data in the same project folder.

| Collection | Contents |
| --- | --- |
| [Terminal](terminal/) | Blackjack, number guessing, rock/paper/scissors, a text adventure, Hangman, higher/lower, and a quiz. |
| [Turtle](turtle/) | Pong, Snake, traffic crossing, a turtle race, and a map quiz. |
