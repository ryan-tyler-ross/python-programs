# Pong

Entry: `python3 games/turtle/pong/main.py`. Standard library; graphical desktop with Tk support.
Left player: W/S. Right player: Up/Down. First to three points wins; click to close.

- [main.py](main.py): game loop and collision checks.
- [ball.py](ball.py): ball movement, bounce, and speed.
- [paddle.py](paddle.py): bounded paddle movement.
- [scoreboard.py](scoreboard.py): scores and winner display.
