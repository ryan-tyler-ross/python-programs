# US states quiz

[main.py](main.py) places guessed state names on a Turtle map using pandas lookups.
Type `Exit` or cancel to write the unguessed names to `missing_states.csv` beside the script.
Generated output is ignored by Git.

Entry: `python3 games/turtle/states-quiz/main.py`.
Dependency: [pandas](requirements.txt), plus a graphical desktop with Tk support.

- [50_states.csv](50_states.csv): state names and map-label coordinates.
- [blank_states_img.gif](blank_states_img.gif): map background.
- [sample_missing_states.csv](sample_missing_states.csv): retained example of the output format.
