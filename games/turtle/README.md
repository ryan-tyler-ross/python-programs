# Turtle games

All require a graphical desktop with Tk support.

| Program | Controls or behavior |
| --- | --- |
| [Pong](pong/) | Two players, paddle collisions, and scoring. |
| [Snake](snake/) | Arrow-key movement, growth, and collisions. |
| [Turtle crossing](turtle-crossing/) | Avoid traffic that gets faster after each crossing. |
| [Turtle race](turtle-race/) | Pick a color and watch randomized movement. |
| [US states quiz](states-quiz/) | Name states on a map; uses pandas for saved coordinates. |
