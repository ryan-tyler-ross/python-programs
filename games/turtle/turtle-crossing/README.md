# Turtle crossing

Entry: `python3 games/turtle/turtle-crossing/main.py`.
Standard library; graphical desktop with Tk support.
Up moves forward. Each completed crossing makes the cars faster; click to close after the game.

- [main.py](main.py): game loop and collisions.
- [player.py](player.py): turtle movement and reset.
- [car_manager.py](car_manager.py): traffic spawning, movement, and speed.
- [scoreboard.py](scoreboard.py): level and game-over display.
