# Templates

Small, standalone files to adapt when a similar task comes up. API endpoints,
authentication, and response shapes belong to the system the template is used with.

| Template | Reference |
| --- | --- |
| [HTTP requests](http/) | Timeouts, server-error retries, backoff, rate limits, and partial results. |
| [RESTCONF](restconf/) | A read-only JSON request using environment-based lab settings. |
| [Tkinter widgets](tkinter/) | Common widgets and their callbacks in one window. |
