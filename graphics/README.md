# Graphics

Turtle drawing programs and an image color extractor.

| Folder | Example |
| --- | --- |
| [Color palette](color-palette/) | Draw a dot grid from saved RGB values or extract colors from an image. |
| [Etch-a-sketch](etch-a-sketch/) | Keyboard callbacks for movement, turning, and clearing. |
| [Spirograph](spirograph/) | Repeated circles with changing angles and random colors. |

Drawings require a graphical desktop with Tk support; click the window to close.
