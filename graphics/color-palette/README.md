# Color palette

- [color_palette.py](color_palette.py): draw a 10×10 dot grid using a saved RGB palette.
- [color_extractor.py](color_extractor.py): print 12 RGB colors sampled from the bundled image.
- [hurst-spot-painting.jpg](hurst-spot-painting.jpg): reference image.

Drawing entry: `python3 graphics/color-palette/color_palette.py`.
Standard library; graphical desktop with Tk support. Click to close.
Extraction entry: `python3 graphics/color-palette/color_extractor.py`.
Dependency for extraction only: [colorgram.py](requirements.txt).
