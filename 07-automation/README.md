# APIs and automation

Fetch JSON, handle failures, and read from a network lab.

- [ISS alerts](iss-tracker-with-alerts/README.md) — Read two public APIs and print an alert when the ISS is near Area 51 at night.
- [HTTP examples](http-examples/README.md) — Each short script teaches one failure-handling pattern and can run on its own.
- [RESTCONF lab](restconf-lab/README.md) — Read a JSON resource from a device in your own lab.
- [Cisco ISE starter](cisco-ise/README.md) — The source file was empty. This folder preserves that unfinished exercise.

Start from the course root with your own lab URL: `python 07-automation/http-examples/timeouts.py https://your-lab.example/api`.
The ISS project uses public APIs; RESTCONF needs local settings; the ISE file is an unfinished starter.
