# US states quiz

Combine pandas data lookup with Turtle graphics.

From the course root: `python 05-files/states-quiz/main.py`.

Requires pandas and a graphical desktop. Type Exit or cancel the prompt to save missing states.

- `main.py` — Guess state names on the map; Exit or Cancel saves unguessed states.
- `50_states.csv` — State names and label coordinates for the included map.
- `blank_states_img.gif` — Blank US map used as the Turtle background.
- `states_to_learn.csv` — Saved example output; a later game replaces it with your missing states.
