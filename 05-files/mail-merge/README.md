# Mail merge

Edit the template and names, then generate one letter per recipient.

From the course root: `python 05-files/mail-merge/mail_merge.py`.

letters/ contains the output and its README. Running again replaces letters with the same number.

- `mail_merge.py` — Read the two inputs and write numbered personalized letters into letters/.
- `template.txt` — Letter template; [name] marks where each person's name goes.
- `names.txt` — One recipient per line; blank lines are skipped.
