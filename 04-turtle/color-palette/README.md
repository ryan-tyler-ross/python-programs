# Color palette

Draw with a fixed palette, or sample colors from the included image.

From the course root: `python 04-turtle/color-palette/color_palette.py`.

To sample the image: python color_extractor.py (requires colorgram.py).

- `color_palette.py` — Draw a 10×10 grid with a saved palette; click to close.
- `color_extractor.py` — Print 12 sampled RGB colors; needs colorgram.py.
- `hurst-spot-painting.jpg` — Reference painting for the color extractor.
