# Pong

Explore cooperating classes and collision checks.

From the course root: `python 04-turtle/pong/main.py`.

Left player: W/S. Right player: Up/Down. First to three points wins; click to close.

- `main.py` — Run two-player Pong; first to three points wins.
- `ball.py` — Move the ball, bounce it, and increase its speed.
- `paddle.py` — Move a paddle up and down within the window.
- `scoreboard.py` — Display both scores and announce the winner.
