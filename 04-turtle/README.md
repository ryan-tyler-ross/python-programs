# Drawing and games

Learn coordinates and keyboard events before trying the larger games.

- [Spirograph](spirograph/README.md) — Practice loops, angles, and RGB colors.
- [Etch-a-sketch](etch-a-sketch/README.md) — Practice keyboard callbacks and turtle movement.
- [Color palette](color-palette/README.md) — Draw with a fixed palette, or sample colors from the included image.
- [Turtle race](turtle-race/README.md) — Practice lists of objects and random movement.
- [Snake](snake/README.md) — Explore classes, movement, growth, and collisions in one script.
- [Pong](pong/README.md) — Explore cooperating classes and collision checks.
- [Turtle crossing](turtle-crossing/README.md) — Cross the traffic with Up; each successful crossing makes the cars faster.

Start from the course root: `python 04-turtle/spirograph/spirograph.py`.
These projects need a graphical desktop and Tk support. Try drawings before games.
