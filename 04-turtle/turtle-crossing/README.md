# Turtle crossing

Cross the traffic with Up; each successful crossing makes the cars faster.

From the course root: `python 04-turtle/turtle-crossing/main.py`.

Click to close after the game.

- `main.py` — Run the crossing game; Up moves the turtle forward.
- `player.py` — Move the turtle and reset it after each crossing.
- `car_manager.py` — Spawn and move cars; successful crossings increase their speed.
- `scoreboard.py` — Show the current level and game-over message.
