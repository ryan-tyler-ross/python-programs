# Coffee-machine simulations

Two implementations of the same small ordering problem: fixed drink recipes,
limited ingredients, coin payments, change, and a stock/profit report.

| Entry | Structure |
| --- | --- |
| [procedural.py](procedural.py) | Dictionaries and functions in one file. |
| [classes/main.py](classes/main.py) | Separate menu, machine, and payment objects. |

Run either file directly, for example `python3 utilities/coffee-machine/procedural.py`.
Type `report` for inventory and profit, or `off` to quit. Standard library only.
