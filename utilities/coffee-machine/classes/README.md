# Coffee machine with classes

Entry: `python3 utilities/coffee-machine/classes/main.py`. Standard library only.

| File | Responsibility |
| --- | --- |
| [main.py](main.py) | Connect the menu, payment, and machine objects. |
| [menu.py](menu.py) | Drink recipes, prices, and lookup. |
| [coffee_maker.py](coffee_maker.py) | Ingredient checks, deductions, and inventory reports. |
| [money_machine.py](money_machine.py) | Coin input, change, and profit. |

The [procedural version](../procedural.py) keeps the same problem in one file.
