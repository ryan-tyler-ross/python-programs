# Utilities

Small terminal programs, file-processing examples, and two versions of a simple simulation.

| File or folder | Purpose |
| --- | --- |
| [calculator.py](calculator.py) | Arithmetic with an optional running result. |
| [tip_calculator.py](tip_calculator.py) | Split a bill including a tip. |
| [pizza_calculator.py](pizza_calculator.py) | Total a sample order from fixed prices. |
| [password_generator.py](password_generator.py) | Generate and shuffle a 27-character password using `secrets`. |
| [caesar_cipher.py](caesar_cipher.py) | Shift letters while preserving spaces and punctuation. |
| [blind_auction.py](blind_auction.py) | Collect sample bids and select the highest; ties favor the first bid. |
| [band_name_generator.py](band_name_generator.py) | Combine two text inputs into a name. |
| [Coffee machine](coffee-machine/) | Procedural and class-based inventory/payment simulations. |
| [Mail merge](mail-merge/) | Generate text files from a template and a list of sample names. |
| [Weather CSV](weather/) | Summarize temperatures with `csv.DictReader`. |

All use the standard library. Entry example: `python3 utilities/calculator.py`.
